## 命名规范

### URL常量命名

```objective-c
// 格式：kRoute + 模块名 + 功能名
static NSString *const kRouteGoodsDetail = @"//goods/detail";
static NSString *const kRouteGoodsList = @"//goods/list";
static NSString *const kRouteUserProfile = @"//user/profile";
```

### Service协议命名

```objective-c
// 格式：模块名 + ModuleService
@protocol GoodsModuleService <NSObject>
@protocol UserModuleService <NSObject>
@protocol OrderModuleService <NSObject>
```

### Model协议命名

```objective-c
// 格式：模型名 + Protocol
@protocol GoodsProtocol <NSObject>
@protocol UserProtocol <NSObject>
@protocol OrderProtocol <NSObject>
```

## 代码组织

### 模块内部组织

1. **Module**：模块入口，实现BifrostModuleProtocol
2. **Model**：数据模型，实现Model协议
3. **Manager**：业务逻辑管理
4. **Controller**：UI控制器
5. **Common**：模块内公共代码

### 文件组织

```
Module/
├── Module/         # 模块入口
├── Model/          # 数据模型
├── Manager/        # 业务逻辑
├── Controller/     # UI控制器
└── Common/         # 公共代码
```

## 性能优化

### 1. 缓存模块实例

```objective-c
@interface ShoppingCartViewController ()
@property (nonatomic, strong) id<GoodsModuleService> goodsModule;
@end

- (void)viewDidLoad {
    [super viewDidLoad];
    // 缓存模块实例
    self.goodsModule = BFModule(GoodsModuleService);
}
```

### 2. 异步初始化

```objective-c
- (void)setup {
    // 在后台线程初始化
    dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
        [self loadData];
    });
}
```

## 常见问题

### Q1: BFModule返回nil

**原因**：模块未注册或未初始化

**解决**：
1. 检查+load方法中是否调用了BFRegister
2. 检查AppDelegate中是否调用了setupAllModules
3. 检查模块类是否实现了BifrostModuleProtocol

### Q2: Router URL返回nil

**原因**：URL未注册或格式错误

**解决**：
1. 检查+load方法中是否调用了bindURL
2. 检查URL格式是否正确
3. 在bindURL的handler中添加断点调试

## 开发建议

1. **模块独立性**：业务模块之间不能有代码依赖
2. **接口最小化**：只暴露必要的API
3. **协议优先**：使用协议类型而不是具体类
4. **异常处理**：完善的nil检查和异常处理
5. **性能优化**：缓存模块实例，异步初始化
6. **测试完善**：编写单元测试和集成测试
